# Bank Loan Calculator (PS No. 70)

## Project Overview
A Python console application designed to calculate monthly EMI, total payable amount, and total interest for a bank loan. It also validates user inputs and checks applicant eligibility based on their monthly income[span_2](start_span)[span_2](end_span).

## Features
- **EMI Calculation:** Computes accurate monthly EMI using standard banking formulas and handles zero-interest cases[span_3](start_span)[span_3](end_span).
- **Financial Breakdown:** Calculates total payable amount and total interest over the loan tenure[span_4](start_span)[span_4](end_span).
- **Eligibility Check:** Automatically checks if the calculated EMI is within 40% of the applicant's monthly income[span_5](start_span)[span_5](end_span).
- **Input Validation:** Validates principal amount, interest rate, tenure, and income ranges with error messages[span_6](start_span)[span_6](end_span).
